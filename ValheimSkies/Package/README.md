# 🌌 HD Valheim Skies

Replace Valheim's night sky with HD space skies: galaxies, nebulae and deep fields, in 2048 x 2048 per cube face. Pick the sky you like, or get a random one each time you enter a world.

## ✅ Features:

  * **13 HD skies**, each a full 6-face cubemap.
  * Change the sky **while playing**, from the in-game settings panel (F7). No restart needed.
  * **Random Sky**: a different sky each time you enter a world.
  * **Vanilla** option to go back to the game's own sky.
  * **Hide Yggdrasil** option to hide the big tree that grows up into the sky.
  * **Volumetric clouds** (optional, off by default): 3D clouds that follow the weather, with a physically based daytime sky, cloud shadows and high cirrus.
  * **Weather** setting to hold the game on one weather.
  * Only the sky you are using is kept in memory.
  * Client side: you do not need the server to have it, and it does not change gameplay.
  * Translated into 9 languages.

## ⚙️ Settings:

Press **F7** in game to open the settings panel, or edit `BepInEx/config/MagicMike.ValheimSkies.cfg`.

| Setting | Default | What it does |
|---|---|---|
| Enable Plugin | On | Turns the mod on or off. Needs a restart. |
| Sky | Nebula Sunrise | The sky to show. Vanilla keeps the game's own sky. |
| Random Sky | Off | Picks a different sky each time you enter a world. The Sky setting is ignored. |
| Show Message | On | Shows which sky is showing in the top-left corner when it changes. |
| Hide Yggdrasil | Off | Hides the big tree (Yggdrasil) that grows up into the sky. Changes straight away in a world. |
| Volumetric Clouds | On | 3D clouds that follow the weather: fair-weather cumulus under soft veils, grey textured decks in rain and storms, dark clouds at night, pink and lavender at sunset. Changes straight away in a world. |
| Cloud Quality | Medium | How carefully the clouds are drawn. Lower it if the game slows down. |
| Cloud Amount | 1 | How much of the sky the clouds cover, on top of what the weather brings. 0 is no clouds. |
| Cloud Brightness | 1 | How brightly the sun, the moon and the sky light the clouds. |
| Night Brightness | 0.3 | How brightly the clouds are lit at night. |
| Cloud Shadows | 0.6 | How dark the clouds' shadows on the ground are. 0 is no shadows. |
| High Clouds | Weather | Cirrus streaks high up and small altocumulus: on some days (Weather), on every dry day (Always), or never (Off). |
| Atmosphere Sky | On | With Volumetric Clouds, the daytime sky is a physically based atmosphere the clouds are lit by. Your chosen sky still shows at night. |
| Hide Game Clouds | On | Hides the game's own flat cloud layers while the volumetric clouds show. |
| Weather | Natural | Holds the game on one weather. Natural leaves it to the game. |

If you use Weather Overhaul's own clouds, leave Volumetric Clouds off: two cloud systems would draw over each other.

<br>

## 🌍 Translations:

The translation files are in `BepInEx/config/ValheimSkies/Translations/<Language>/ValheimSkies.json`. Edit them, or add a language, and restart the game.

<br>

## 💻 Installation:

### Automatic Install

Plugin is created to be installed with r2modman or Gale.
For Nexus downloads you will need to install manually.

### Manual Install

  * Un-zip and drag the `ValheimSkies` folder in your `BepInEx/plugins/` folder.
