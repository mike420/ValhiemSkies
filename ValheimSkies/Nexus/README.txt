[size=6][b]HD Valheim Skies[/b][/size]

Replace Valheim's night sky with HD space skies: galaxies, nebulae and deep fields, in 2048 x 2048 per cube face. Pick the sky you like, or get a random one each time you enter a world.

[size=5][b]Features[/b][/size]

[list]
[*][b]13 HD skies[/b], each a full 6-face cubemap.
[*]Change the sky [b]while playing[/b], from the in-game settings panel (F7). No restart needed.
[*][b]Random Sky[/b]: a different sky each time you enter a world.
[*][b]Vanilla[/b] option to go back to the game's own sky.
[*][b]Hide Yggdrasil[/b] option to hide the big tree that grows up into the sky.
[*]Only the sky you are using is kept in memory.
[*]Client side: you do not need the server to have it, and it does not change gameplay.
[*]Translated into 9 languages.
[/list]

[size=5][b]Settings[/b][/size]

Press [b]F7[/b] in game to open the settings panel, or edit [b]BepInEx/config/MagicMike.ValheimSkies.cfg[/b].
[list]
[*][b]Enable Plugin[/b] (default On): Turns the mod on or off. Needs a restart.
[*][b]Sky[/b] (default Nebula Sunrise): The sky to show. Vanilla keeps the game's own sky.
[*][b]Random Sky[/b] (default Off): Picks a different sky each time you enter a world. The Sky setting is ignored.
[*][b]Show Message[/b] (default On): Shows which sky is showing in the top-left corner when it changes.
[*][b]Hide Yggdrasil[/b] (default Off): Hides the big tree (Yggdrasil) that grows up into the sky. Changes straight away in a world.
[/list]

[size=5][b]Translations[/b][/size]

The translation files are in [b]BepInEx/config/ValheimSkies/Translations/<Language>/ValheimSkies.json[/b]. Edit them, or add a language, and restart the game.

[size=5][b]Installation[/b][/size]

### Automatic Install
Plugin is created to be installed with r2modman or Gale.
For Nexus downloads you will need to install manually.
### Manual Install
[list]
[*]Un-zip and drag the [b]ValheimSkies[/b] folder in your [b]BepInEx/plugins/[/b] folder.
[/list]
