# ValheimSkies

Valheim mod that swaps the night sky for HD space skies. The sky images are built into the `valheim_skies`
asset bundle by the Unity project at `E:\Unity_Projects\ValhiemSkies` (menu **Valheim Skies > Build Skies Bundle**),
then copied into `ValheimSkies/Resources/`.

Build: VS MSBuild `ValheimSkies.sln -restore -p:Configuration=Release`.
